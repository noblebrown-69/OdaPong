# Bare-Bones Pong - by Oda

A simple, lightweight Pong implementation written in C++ using the SDL2 library, and built entirely by my local LLM, Oda.

You can find details on the Oda project here:  https://github.com/noblebrown-69/Oda 

## 🚀 Prerequisites

Before building and running the game, ensure you have the following installed:

* **C++ Compiler:** `g++` (standard on most Linux distributions)
* **Build Tool:** `make`
* **SDL2 Library:** You can install it on Linux Mint/Ubuntu using:
  ```bash
  sudo apt-get update
  sudo apt-get install libsdl2-dev
  ```

## 🛠️ Installation & Running

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd pong_project/pong_game
   ```

2. **Build the game:**
   ```bash
   make
   ```

3. **Run the game:**
   ```bash
   ./pong
   ```

## 🎮 Controls

* **Left Paddle:** 
    * `W` - Move Up
    * `S` - Move Down
* **Right Paddle:** 
    * `Up Arrow` - Move Up
    * `Down Arrow` - Move Down
* **Quit:** Close the game window.
